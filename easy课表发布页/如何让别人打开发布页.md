# 为什么“打不开”？怎么让别人才打开？

## 现状说明
“easy课表发布页”目前只是你电脑里的一个文件夹，没有网址（URL）。
- 别人不在你旁边、不在你同一个 Wi-Fi，是打不开的；
- 即使你自己双击 index.html，也只会是本机浏览，APK 下载可能被浏览器拦截。

要让“别人也能打开并下载”，必须把它放到一个有公网地址的地方。下面给你 3 种做法，按推荐顺序：

## 做法 1：传网盘，直接发 APK 链接（最快、最省事）★推荐
1. 打开蓝奏云（https://pc.woozooo.com）或夸克网盘 / 百度网盘；
2. 把 `easy课表-1.0.1.apk`（本文件夹里）上传；
3. 开启分享，把链接发给对方；对方在手机浏览器打开即可下载安装。
> 适合：只是想让同学/朋友装上 APK。

## 做法 2：免费静态托管，让别人打开“发布网页”（要一个账号）
把整个“easy课表发布页”文件夹发布成网页，别人访问网址即可看到页面并点“下载安卓版”。
推荐（免服务器、免费）：
- Netlify Drop：手机/电脑浏览器打开 https://app.netlify.com/drop ，把整个文件夹拖进去，几秒后得到一个 https://xxxx.netlify.app 网址，发出去即可（首次需免费注册）。
- 或 Vercel：https://vercel.com 拖拽部署。
- 或国内 Gitee Pages：把文件夹传到 Gitee 仓库后用 Pages 功能。

发布时注意事项：
- 把文件夹里所有文件一起传（index.html / easy课表-1.0.1.apk / logo.png / server.js）；
- 保持 apk 和 index.html 在同一个目录，这样页面上的“下载安卓版”按钮才会指向正确的 APK；
- 上传后先自己用手机浏览器打开网址测试一次“下载”。

## 做法 3：局域网（同一 Wi-Fi 的人能下载，不需要公网）
双击本文件夹里的 `启动下载服务器.cmd`：
- 电脑打开 http://127.0.0.1:8899 测试；
- 手机连同一个 Wi-Fi，浏览器打开终端提示的地址（形如 http://192.168.x.x:8899）即可下载。
> 限制：只有和你同一 Wi-Fi、且你电脑开机时能用；不能给外网的人。

## 小贴士
- 每次出新版本，把新的 `easy课表-x.x.x.apk` 放到发布文件夹并更新 `index.html` 里的版本与链接，再重新上传即可；
- 别人安装时如提示“未知来源”，需在手机设置中允许“安装未知应用”。
